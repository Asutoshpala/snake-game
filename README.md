# 🐍 Snake Game in C

A simple Snake Game developed using the **C programming language** and **Raylib** library.

## 🎮 Features

- Control the snake using keyboard arrow keys
- Eat food to increase the score
- Snake grows when it eats food
- Game ends when the snake hits the wall or itself
- Displays the current score

## 🛠️ Technologies Used

- **Programming Language:** C
- **Graphics Library:** Raylib
- **Compiler:** GCC
- **IDE:** Visual Studio Code

## 🎯 Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Asutoshpala/snake-game.git
```

### 2. Open the project folder

```bash
cd snake-game
```

### 3. Compile the program

If Raylib is properly installed:

```bash
gcc snake.c -o snake.exe -lraylib -lopengl32 -lgdi32 -lwinmm
```

### 4. Run the game

```bash
./snake.exe
```
